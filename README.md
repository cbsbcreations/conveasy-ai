# conveasy.ai

The international Conveasy website (English first, plus Dutch, French, Turkish and German), served by GitHub Pages from `docs/`.

The pages are generated, so do not edit them here. The source is the repo `cbsbcreations/conveasy-site`:

    python3 src/build.py        # in conveasy-site: builds conveasy.be into docs/ and conveasy.ai into ai/

then copy `ai/` into this repo's `docs/` (replacing what is there) and push.
